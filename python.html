Variables and Variable Types!

In python there are four main data types we will be focusing on...

  • Integers
  • String
  • Float
  • Boolean

Integers

Integers or int used to define a whole number.

Examples

-1, 0, 1, 5, 68

[!] This can be used to perform calculations [!]

Floats

Float is used to define a non whole number.

Examples

3.3, 6.9, 4.2, 31.6

[!] This can be used to perform calculations [!]

Strings

String or str is used to define any word, letter or number that needs to be read typically using Quotation marks around the needed object.

Examples

"Hello there!", "This is some text.", "The quick brown fox jumps over the lazy dog."

Booleans

Boolean is either true or false, it can be used to check if values are equal to each other or if certain cases meet certain standards.

Examples

(5 == 5) --> TRUE

(4 > 9) --> FALSE

Lesson 3

If/Else Statements

If statements use a condition to decide if a value meets said conditions.

If Statements

Integers or int used to define a whole number.

Examples

num1 = 5

if num1 == 5:

print("Hi")



OUTPUT: Hi

Else Statements

Else statements do not have a condition and will automatically be used if the if statement is not met.

Examples

num1 = 5

if num1 == 6:

print("Hi")

else:

print("Bye")



OUTPUT: Bye

Elif Statements

Else statements do not have a condition and will automatically be used if the if statement is not met.

Examples

num1 = 5

if num1 == 6:

print("Hi")

elif num1 == 5:

print("Pardon?")

else:

print("Bye")



OUTPUT: Pardon?
