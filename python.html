Welcome to Python!

In this lesson, you’re going to create your first program.

Setting Things Up

First, you’re going to need something that can run your program using an interpreter. This allows your computer to interpret the English language to create programs that it can run.

The most widely-known used analogy of how interpreters work is a translator, allowing you and your computer to communicate.

There are many online resources such as Programiz and OnlineGDB that allow you to run Python in the browser.

(It’s also a feature we’re hoping to implement in the future! ;])

However, you can also download python onto your computer to use it locally!"

Download it Here!

So, let’s try to output a message!

We can do this using the print(“”) function.

The print function basically outputs any value that is within the parentheses.

Here’s an example!

print(“Hello!”)

OUTPUT: Hello!

Change things up! The following code outputs 2 as a number!

print(2)

OUTPUT: 2

Copy the print statement and put it into your interpreter, and if it runs, congratulations. You’ve created your first program! :D

Try to change what the message inside of the print statement says.
